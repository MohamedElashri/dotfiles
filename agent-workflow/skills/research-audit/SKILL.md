# Research audit

1. Identify the actual question being decided and enumerate consequential claims.
2. Decide what evidence each claim needs: primary documentation, a paper,
   standard, source repository, measured behavior, or external data. Verify
   source identity, version, date, and relevance as appropriate.
3. Seek independent corroboration or disconfirming evidence when the stakes or
   disagreement justify it. Do not multiply low-quality citations.
4. Separate directly supported statements from inferences. Identify missing
   data, assumptions, and uncertainty that could change the decision.
5. Resolve contradictions when the evidence permits; otherwise preserve the
   uncertainty instead of forcing consensus.
6. Return a concise claim/evidence/verdict summary with source references and
   key caveats. If unsettled, give the next falsifiable check.

Never invent source contents or claim to have read a paper you did not access.
Do not present secondary summaries as primary evidence. If tools or network
access are unavailable, report the resulting verification limit. Do not invent
confidence percentages. Keep research bounded to the question; do not start
continuous crawling or make arbitrary external writes.

An audit is read-only by default. Change artifacts only when the invoking task
authorizes edits; research does not itself authorize external actions.
